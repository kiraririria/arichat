📦 Установка Arichat Classic

Arichat Classic — это мод для Minecraft, который добавляет AI-функциональность прямо в игру.

Требования:

  • Minecraft 1.12.2
  • Forge
  • Java 8+
  • Mappet 0.9 и другие зависимости
  • Доступ в интернет или локальная модель

Шаги установки:

  1. Скачайте последнюю версию Arichat Classic со страницы релизов
  2. Поместите файл .jar в папку mods вашего клиента Minecraft
  3. Добавьте Mappet и другие необходимые моды McHorse
  4. Запустите Minecraft
  5. Настройте мод через меню

🪄 Макросы Arichat Classic

Макросы - это специальные команды, которые позволяют динамически вставлять различную информацию в промпты

Макрос Описание
{{mps:key}} Стейт Mappet игрока (поддерживает вложенность)
{{emo:key}} Эмоция ответа для Макросных Эмоциональных Реакций
{{roll:XdY}} Бросает X кубиков с Y гранями
{{random:A,B,C}} Случайный выбор из списка (новый каждый раз)
{{pick:A,B,C}} Случайный выбор из списка (кэшируется)
{{sc:код_JavaScript}} Исполнение JavaScript кода при построении промпта (с выводом результата)
{{sc:файл.js}} Исполнение кода из файла при построении промпта (с выводом результата)
{{js:код_JavaScript}} Исполнение кода из ответа модели (без вывода результата)
{{js:файл.js}} Исполнение Файла кода из ответа модели (без вывода результата)
{{pattern}} Системный промпт становится Шаблоном построения всего промпта
{{newline}} Вставляет символ переноса строки
{{char}} Имя персонажа NPC
{{user}} Имя пользователя (игрока)
{{description}} Описание персонажа из карточки
{{personality}} Личность персонажа из карточки
{{scenario}} Сценарий беседы из карточки
{{mesExamples}} Примеры сообщений из карточки
{{systemPrompt}} Системный промпт беседы
{{persona}} Персона игрока из Mappet
{{summary}} Суммаризация предыдущих событий
{{time}} Игровое время (24-часовой формат)
{{date}} Игровой день
{{weekday}} День недели
{{isotime}} Реальное время (HH:mm:ss)
{{isodate}} Реальная дата (yyyy-MM-dd)
{{time_UTC±часы}} Время в указанном часовом поясе UTC
{{reverse:текст}} Обратная строка (переворачивает текст)
{{lastMessage}} Последнее сообщение в диалоге
{{lastUserMessage}} Последнее сообщение игрока
{{lastCharMessage}} Последнее сообщение NPC
{{lastMessageId}} ID последнего сообщения
{{history}} Вся история диалога
💡 Примечание: Макросы можно комбинировать и использовать в любых текстовых полях Arichat Classic, которые будут использоваться в промпте
